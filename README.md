# 🎉 EventEase: Event Planning System

## 📌 Overview

**EventEase** is a Java-based desktop application designed to simplify event planning and management. It allows users to create, store, and manage event details efficiently using a user-friendly interface.

This project is built using **Java Swing** for the UI and **SQLite** for database management.

---

## 🚀 Features

* 🔐 User Login System
* 📊 Dashboard for navigation
* 📝 Create and store event details
* 💾 Save event data into SQLite database
* 🔄 Easy-to-use interface with smooth navigation

---

## 🛠️ Tech Stack

* **Frontend (UI):** Java Swing
* **Backend Logic:** Java
* **Database:** SQLite
* **Connectivity:** JDBC
* **IDE:** VS Code

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/EventEase.git
```

### 2. Navigate to the project folder

```
cd EventEase
```

### 3. Open in VS Code

* Open folder in VS Code
* Ensure JDK is installed

### 4. Run the project

* Run the `Main.java` file

## 🗄️ Database

* The project uses **SQLite**
* Database file: `eventease.db`
* Contains table:

  * `events` → stores event details like name, date, location, etc.
